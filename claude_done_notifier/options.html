Claude Done Notifier 设置

在 resend.com 注册后创建 API Key。未验证域名时，发件人用 onboarding@resend.dev，且只能发给注册 Resend 的那个邮箱。
模板中可用变量：{{to_email}} {{subject}} {{message}} {{title}} {{url}}。 EmailJS 后台 Account → Security 需勾选 “Allow EmailJS API for non-browser applications”。
POST JSON：{to, subject, text, title, url, durationSec, reply}。可对接自己的服务器、Make / Zapier / n8n 等发邮件。
